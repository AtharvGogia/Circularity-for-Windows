## Circularity 0.6.2

### Fixes
- **"Copy results to the clipboard" works with finish notifications turned off.** Before, results were only copied when the "Done" notification was shown. A PDF that becomes a folder of pages now has that folder copied too.
- **Watched folders don't touch your clipboard.** Their results arrive without you asking, so they no longer replace whatever you had copied. Results from the wheel are still copied as before.
- **Shift can't get stuck "held".** If a key-up was lost (to a UAC prompt or the lock screen, say), Circularity could think Shift was still down and not open the wheel when you pressed it during a drag. It now checks the real state of the key each time you start a drag.
- **A picture FFmpeg can't finish reading is given up on** after a minute, rather than holding up the queue.
- **Combining files into a PDF can be cancelled** with **Cancel conversions**, between files and pages.
- **A watched folder won't convert Circularity's own result** when two conversions of the same file finish close together.
- **Markdown and HTML in a folder with "&" in its name** (such as "R&D&copy") keep the pictures and styles beside them.

### Install
Download **CircularitySetup-0.6.2.exe** below and run it, or use **Check for updates** in the tray menu if you already have Circularity.

Windows may show a SmartScreen warning because the installer isn't code-signed: click **More info → Run anyway**.

## For developers

**Clipboard** (`App.Results.cs`)
- The copy runs before the notification is chosen, so it no longer depends on `NotifyOnFinish`. `ClipboardPathsFor` keeps outputs that exist as files or folders.
- `ConversionBatch.FromWatchedFolder` is set by `OnWatchedFilesArrived` right after `Enqueue`, and those batches skip the copy. That's safe without a lock: `ReportBatch` runs on the UI thread through `BeginInvoke`, after `OnWatchedFilesArrived` has returned.

**Output names** (`Engine/OutputPaths.cs`)
- `Reserve` remembers a candidate with `TryAdd` and only forgets it on failure if it added it. Before, a collision with another conversion's result removed that result from `Produced`, so a watched folder could pick it up. A folder with the candidate's name is skipped.
- `PdfConverter` forgets the placeholder file when a multi-page PDF becomes a pages folder.

**FFmpeg** (`Engine/FfmpegConverter.cs`)
- `DecodeImageToPng` and `HasAlphaPicture` read stderr asynchronously and then `WaitForExit` with their limits (60 s and 10 s). Before, a blocking `ReadToEnd` came first, so the limit never applied, and `HasAlphaPicture` ignored a timeout. On a timeout the process tree is killed.

**Gesture** (`GestureHook.cs`)
- On left button down, `_shiftHeldAtDragStart` and `_shiftDown` come from `GetAsyncKeyState(VK_SHIFT)` rather than from the keyboard hook's last event alone.

**Printing pages to PDF** (`Engine/WebPdfConverter.cs`)
- The `<base href>` is HTML-encoded. `BuildHtml` is split out of `ToHtmlAsync` for the tests.

**PDF** (`Engine/PdfConverter.cs`)
- `BuildPdf` checks the cancellation token before each file and page and before saving.

**Tests**
- Reserve keeps a colliding result marked as Circularity's, and skips a folder of the same name; the clipboard paths include a pages folder and leave out missing ones; the base href escapes `&`.
- 170 unit tests and 125 smoke checks pass.
